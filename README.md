# GSM Sidi Moumen

Site vitrine premium du centre de soutien scolaire **GSM Sidi Moumen** (Groupe Superprof Mohssine).

## Lancer le projet

```bash
npm install
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000).

## Stack

Next.js 15, TypeScript, Tailwind CSS, React Three Fiber, Three.js, Framer Motion, GSAP, Lucide Icons.
